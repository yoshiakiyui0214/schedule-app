# 要件定義書

## 1. プロジェクト概要

- **背景**: 予定を書き込める場所がなく、事前に知らせてくれる仕組みもないため、うっかり忘れがちだった。自分専用で使いやすい予定管理・通知アプリが欲しい。
- **目的**: 予定を簡単に登録し、事前に通知を受け取ることで、予定忘れをなくし安心して日々を過ごせる状態を実現する。
- **スコープ**:
  - 含むもの: 個人利用向けの予定登録・一覧確認・事前通知・編集/削除
  - 含まないもの（今回は対象外）: 複数人での予定共有、他カレンダーサービスとの連携、AIによる自動提案

---

## 2. ユーザーストーリー

As a 個人利用ユーザー，
I want 予定を登録して事前に通知してもらえること，
So that 予定を忘れずに安心して行動できる。

その他の主要ストーリー：

- As a 個人利用ユーザー, I want 予定を一覧やカレンダーで確認できること, So that 今後の予定を把握して計画を立てられる。
- As a 個人利用ユーザー, I want 通知タイミングを自分で調整できること, So that 自分の生活リズムに合わせて知らせてもらえる。
- As a 個人利用ユーザー, I want 予定を編集・削除できること, So that 予定変更にすぐ対応できる。

---

## 3. 機能要件

| ID | 機能名 | 説明 | 優先度 | Phase |
|---|---|---|---|---|
| F-01 | 予定登録 | タイトル・日時を入力して保存 | 高 | MVP |
| F-02 | 予定一覧表示 | 登録済み予定を日付順にリスト表示 | 高 | MVP |
| F-03 | 予定詳細表示 | 個別の予定の内容を確認 | 高 | MVP |
| F-04 | 予定編集 | 既存の予定を修正・保存 | 高 | MVP |
| F-05 | 予定削除 | 確認後に予定を削除 | 高 | MVP |
| F-06 | プッシュ通知 | 指定時刻にリマインド通知を送信 | 高 | MVP |
| F-07 | カレンダー表示 | リスト⇔カレンダービューの切替 | 中 | v1.0 |
| F-08 | カテゴリ分け | 予定にカテゴリ（仕事/プライベート等）を付与 | 中 | v1.0 |
| F-09 | 繰り返し設定 | 定期的な予定の繰り返し登録 | 中 | v1.0 |
| F-10 | 通知タイミング設定 | 通知を何分/何時間前に送るか設定 | 中 | v1.0 |
| F-11 | 完了チェック | 予定完了をチェックでマーク | 中 | v1.0 |
| F-12 | 完了履歴表示 | 完了済み予定の一覧を確認 | 低 | v1.0 |
| F-13 | 自然文からの自動登録 | 音声・AIによるテキスト解析で予定登録 | 低 | v2.0 |
| F-14 | 位置連動通知 | ジオフェンスによる位置ベース通知 | 低 | v2.0 |
| F-15 | 統計グラフ | 月間の予定達成率などのレポート表示 | 低 | v2.0 |

---

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| パフォーマンス | 予定一覧の表示は1秒以内、通知は指定時刻±1分以内に配信 |
| セキュリティ | 個人利用のため簡易認証（もしくは端末単位の利用）とし、他者からのデータアクセスを防ぐ |
| 可用性 | Vercelの無料枠稼働時間内で安定動作すること |
| ユーザビリティ | スマートフォンでの利用を主とし、レスポンシブ対応必須 |
| データ永続化 | Supabase等のDBに予定データを保存し、再起動後もデータが保持される |
| 保守性 | Next.jsのコンポーネント単位で機能追加しやすい構成にする |

---

## 5. 制約条件

- **予算**: 無料枠内で完結（Vercel無料プラン、Supabase無料プラン）
- **期間**: 2週間
- **技術スタック**: Next.js + Supabase + Vercel
